# AI Resume Analyzer

## Overview
AI Resume Analyzer is a smart web application that analyzes resumes and provides useful insights such as skill extraction, resume scoring, keyword analysis, and improvement suggestions. The project helps users improve their resumes according to industry and job requirements.

---

## Features
- Resume Upload in PDF format
- Resume Parsing and Text Extraction
- Skill Extraction using NLP
- Resume Score Analysis
- Keyword Matching
- User-Friendly Interface
- Real-Time Resume Analysis
- Resume Improvement Suggestions

---

## Technologies Used
- Python
- Streamlit
- NLP (Natural Language Processing)

- Scikit-learn

- NumPy
